# Privacy Policy — Litterbox for GitHub PRs

_Last updated: 2026-10-23_

Litterbox does **not** collect, transmit, sell or share any personal data.

- **What it stores:** only your exclude patterns (e.g. `*.test.*, *.snap`), saved with `chrome.storage.sync` so they follow your Chrome profile. Nothing else is stored.
- **What it reads:** the GitHub pull request page you are viewing, to find file paths and added/removed line counts. This happens entirely inside your browser.
- **Network:** the extension makes no requests to any server other than github.com. If the page data is out of date after in-page navigation, it re-fetches the same github.com page you are on, with your existing session.
- **No analytics, no tracking, no third parties.**

The source code is public: https://github.com/ai-meow/litterbox

Questions: open an issue at https://github.com/ai-meow/litterbox/issues
